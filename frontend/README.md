# Alebourg frontend

Frontend React/Vite de la tienda, con Axios, TanStack Query, Zustand y
React Hook Form + Zod. Consulta la API local en `http://localhost:8000`.
La estructura y las instrucciones de desarrollo están en el README de la raíz.

```powershell
Copy-Item .env.example .env.local
npm install
npm run lint
npm run dev
```
